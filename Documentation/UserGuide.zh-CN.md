# WrapPin 使用手册

WrapPin 可以让 iPhone 暂时报告一个固定位置，或沿 Apple 地图规划的步行路线移动。请只在你拥有并控制的设备上用于开发和测试。

## 首次设置

开始前需要实体 iPhone、开发者模式和 LocalDevVPN。

1. 打开 WrapPin，完成三页首次使用说明。
2. 在“设备连接”页面轻点“配对本机”。
3. iOS 询问时，允许本地网络权限。
4. 打开“设置 → 隐私与安全性 → 开发者模式 → 与 WrapPin 配对”。
5. 输入 WrapPin 显示的六位数配对码。
6. 安装 LocalDevVPN，并连接它的本地隧道。

一般只需配对一次。配对记录保存在本机钥匙串中，不会上传。

## 选择位置

你可以搜索地点、输入经纬度、轻点地图放置位置点，或从“收藏与历史”中选择。选择搜索结果后，搜索框会自动清空；地点卡片上的关闭按钮会取消当前选择。

## 模拟固定位置

1. 选择地点。
2. 轻点“开始模拟定位”。
3. 如果出现 LocalDevVPN 或蜂窝网络提示，按页面说明操作。
4. 等待连接状态显示“模拟定位中”。

需要更换位置时，选择另一个地点并轻点“更换模拟位置”，无需重新建立整条连接。

结束后轻点“停止模拟并恢复”，确认并保持 WrapPin 在前台，直到真实位置恢复。不要在尚未恢复时使用导航、出行、紧急求助或位置共享类 App。

## Wi-Fi 与蜂窝网络

可在“设置 → 隧道跳转应用”选择 LocalDevVPN（默认）或 Shadowrocket。使用 Wi-Fi 时，WrapPin 会检查已配对 iPhone 的设备连接：能连通就不跳转，无法连通才打开所选应用。蜂窝网络下，LocalDevVPN 保留原有的建立隧道并返回流程，因此启动时仍会打开一次；Shadowrocket 则先检查设备连接，连不上时只打开应用，由用户自行开启。WrapPin 不能直接读取这两个应用的 VPN 开关状态。

Shadowrocket 选项只决定跳转目标，不表示普通代理配置就能提供本机远程配对通道。蜂窝网络下即使它显示已连接，WrapPin 仍可能无法建立设备连接；此时请改用 Wi-Fi。若 Wi-Fi 下也无法通过连接检测，建议保持默认 LocalDevVPN。Shadowrocket 的各类配置与网络组合尚未完成真机验收。

使用 Wi-Fi 时，请确认所选应用的兼容设备隧道已连接。默认使用 LocalDevVPN 时，如果仍然找不到本机，先关闭再开启一次隧道，然后轻点“重试”。连接 Wi-Fi 时不要误选“我正在使用蜂窝网络”。

使用 LocalDevVPN 且仅使用 4G/5G 时：

1. 启动所选位置。
2. 页面提示后，暂时关闭蜂窝网络。
3. 回到 WrapPin，等待它自动发现本机；必要时轻点“继续”。
4. 安全连接建立后，按提示重新开启蜂窝网络。

临时关闭蜂窝网络只用于 LocalDevVPN 建立连接。模拟定位开始后，可以恢复正常使用移动数据。Shadowrocket 不使用这套临时关闭蜂窝数据的引导；如果它在蜂窝网络下无法连接，请切换到 Wi-Fi 后重试。

## 模拟步行路线

1. 选择目的地，轻点“预览步行路线”。
2. 检查路线、距离、预计用时和到达时间。
3. 选择步行速度，再轻点“开始模拟步行”。

步行期间可以暂停、继续，也可以切换到其他 App。到达后可以沿原路线返回，或保留当前连接并选择新的目的地。结束时请使用“停止模拟并恢复”。

首次启动定位会话时，请允许 WrapPin 使用定位服务。该权限只用于在切换到其他 App 后保持当前会话，坐标仍由系统开发者模拟服务写入，后台保持模块不会保存、比较或上传坐标。模拟期间系统可能显示蓝色后台定位指示器；可在“设置 → 连接检测 → 后台保持”查看状态。若拒绝权限，前台模拟仍可运行，但切换 App 后不保证持续。

## 上次任务意外中断

如果 App 未正常结束任务，再次打开时会显示恢复页面：

- “继续模拟定位”会重新连接上次的固定位置。
- “继续模拟步行”会从最近保存的位置准备剩余路线。
- “恢复真实位置”只会短暂重连并清除模拟位置。
- “真实位置已经恢复”会清除本次恢复提示，不再连接。

恢复页面不会自动启动任何任务。

## 收藏、历史与重置

- 收藏会保留到你手动删除或重置 App。
- 历史记录保存最近使用的 30 个位置。
- “重新查看介绍”不会删除任何数据。
- “重置 WrapPin”会删除配对、收藏、历史记录和本地偏好，但不会卸载或修改 LocalDevVPN。

## 连接排查

如果 LocalDevVPN 已连接但仍找不到本机，先确认当前使用的是 Wi-Fi 还是蜂窝网络，再按对应流程重试。如果提示设备与配对记录不符，请重新打开 LocalDevVPN；仍未解决时，移除旧配对并重新配对本机。

需要提交问题时，打开“设置 → 连接检测”，运行检查并复制诊断信息。报告中不要附带配对文件、PIN、账号凭据或私人位置。

## 匿名使用统计

匿名统计默认关闭，只有你主动开启后才会发送少量固定的使用计数。它不会发送坐标、地点、搜索、收藏、路线、配对记录、PIN、设备名称或错误原文。你可以随时在“设置 → 隐私”中关闭。完整说明见 [Privacy](Privacy.md)。
